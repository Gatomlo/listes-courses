Maquette cliquable (données fictives, rien n'est enregistré).

Rôle simulé

Réseau simulé

Coupe le réseau, coche des articles en mode courses, puis rétablis-le.

En membre, les ajouts deviennent des suggestions à valider.

Écrans d'accès

À essayer

  • Liste du 3 oct. → onglet Magasins : économie du split et répartition.
  • Toucher l'étiquette magasin d'un article pour le déplacer.
  • Faire les courses : vue par rayon, cocher, saisir un prix.
  • Menu : ajouter un plat, voir les ingrédients fusionnés dans la liste.
  • Menu : toucher un repas → recette, personnes, changer, retirer.
  • Plats : recherche (nom ou ingrédient), filtres, édition ; ingrédient absent → création dans le catalogue.
  • Faire les courses → Terminer → Scanner le ticket : mise à jour des prix du magasin.
  • Menu → Exporter : aperçu A4, impression, PDF, lien d'affichage.
  • Plats → ＋ Plat → ⤓ Importer : import d'une recette depuis un lien.
  • Réseau simulé : hors-ligne, file d'attente, synchronisation.
  • 🏷 sur un article : promo avec prix pour ces courses ou jusqu'à une date.
  • Toucher un article d'une liste : quantité, note, déplacer, récurrent, retirer. ⋯ : date, clôture, suppression.
  • Catalogue : recherche, filtres (récurrents…), ＋ Produit, fiche éditable, relevé, fusion, suppression.
  • Historique : toucher une liste clôturée.
  • Foyer : suggestions, ordre des rayons, seuil.
